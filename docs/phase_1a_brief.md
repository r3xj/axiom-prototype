# AXIOM Phase 1A Brief

Current build target: no-combat discovery/logistics prototype.

Do build:
- hardcoded local map
- Hearthmere population/labor/supplies
- hourly time advancement
- project system
- prospect surveying
- Redglass discovery
- Material Codex
- deposit claiming
- mine setup
- local stockpiles
- supply shipments
- ore shipments
- testing/analysis
- first material output

Do not build yet:
- raiders
- combat
- AI
- procedural generation
- tactical battles
- trade
- specialists
- gods
- diplomacy
- full economy simulation

Core design rules:
- Resources are local, not global.
- Supplies are physical goods.
- Population is the source of labor and future manpower.
- Projects take time and labor.
- Materials begin unknown and are revealed through survey/testing/research/field use.
- Phase 1A should prove the loop before adding threats.
